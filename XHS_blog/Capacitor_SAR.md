标题｜电容阵列SAR ADC：实现逻辑 + 统一公式区（工程版）

开场：
这篇重新整理成“流程 + 统一公式 + 解释”的结构，重点回答三个问题：
- 为什么是二进制电容阵列？
- 采样后电荷固定时，上极板电压如何变化？
- SAR控制下极板开关时电压如何写成公式？

———
一、最小结构与流程
1) 电容阵列（作为DAC）
- N位二进制权重电容 + 1个额外单位电容

2) 比较器
- 比较上极板电压与 $VDD$（工程里常见 $Vref = VDD$）

3) SAR逻辑
- MSB先试，逐位控制下极板开关

一句话流程：
采样输入 → 断开输入 → 逐位切换下极板 → 比较器判决 → 输出数字码

———
二、统一公式区（全部公式集中在这里）
1) 电容取值与数量
$$C_i = 2^{i} C,\; i=0,1,\dots,N-1$$
$$\text{电容数量} = N \;\text{个加权电容} + 1 \;\text{个单位电容}$$
$$C_{tot} = \sum_{i=0}^{N-1} C_i + C = 2^N C$$

2) 采样相位（上极板接 $V_{in}$，下极板接 $GND$）
$$Q_{top,0} = C_{tot} \cdot V_{in}$$

3) 断开采样后（上极板浮空，电荷守恒）
下极板开关电压：
$$V_{b,i} \in \{0, V_{DD}\}$$
电荷守恒关系：
$$Q_{top} = C_{tot} V_x - \sum_{i=0}^{N-1} C_i V_{b,i}$$
$$Q_{top} = Q_{top,0}$$
得到上极板电压：
$$V_x = V_{in} + \frac{\sum_{i=0}^{N-1} C_i V_{b,i}}{C_{tot}}$$

4) 单位步进（第 $k$ 位从 $0$ 切到 $V_{DD}$）
$$\Delta V_x = \frac{C_k}{C_{tot}} V_{DD} = 2^{k-N} V_{DD}$$

5) 比较器判决
$$V_x \gtrless V_{DD}$$

———
三、公式解释（紧贴工程理解）
1) 为什么二进制电容阵列？
逐次逼近的本质是“每一步试一位”。二进制权重让每次切换只改变对应位的电荷量，误差区间刚好减半，和SAR算法天然匹配。

2) 为什么要加一个单位电容？
多加的单位电容让 $C_{tot}$ 精确等于 $2^N C$，这样每一位的电压步进正好是 $V_{ref}/2^N$；同时它还能改善阵列对称性，减小边缘寄生带来的失配。

3) 断开采样后电压怎么变？
上极板浮空时总电荷近似守恒。SAR逻辑控制下极板切换到 $0$ 或 $V_{ref}$，会改变电荷分布，从而让上极板电压 $V_x$ 逐步上升或下降。每次切换的电压增量由该位电容占总电容的比例决定。

4) 比较器在比什么？
比较器输入的是上极板电压 $V_x$，通常与 $VDD$（或等价的 $V_{ref}$）比较，根据结果确定当前位为1还是0。

———
四、实现细节（容易踩坑）
1) 电容失配
- 高位电容失配直接影响INL
- 版图需共心/交错，单位电容阵列尽量一致

2) 采样开关线性
- 大信号下 $R_{on}$ 变化导致失真
- 常用自举开关提升线性

3) 参考驱动能力
- SAR每次切换都会抽取参考电荷
- 参考缓冲不足会导致码型相关误差

———
五、常见改进方向（精简版）
1) 分段电容阵列
- 降面积、降功耗、减参考负载

2) 单调切换
- 减少参考充放电次数

3) 冗余位与数字校准
- 抗失配、抗比较器误判
