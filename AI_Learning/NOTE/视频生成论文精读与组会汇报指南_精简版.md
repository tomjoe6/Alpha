# 从 DiT 到视频世界模型：论文精读与组会汇报指南

> 覆盖：DiT、Sora、HunyuanVideo、Wan、LingBot-Video，以及 MeanFlow、Improved MeanFlow、Drifting

> 更新：2026-07-15

## 1. 结论先行

这组工作展示了视频生成模型从“图像扩散骨干”走向“可控世界模拟”的演进：

1. **DiT（2023）**：证明 Transformer 可以替代 U-Net，并呈现稳定的规模收益。
2. **Sora（2024）**：用统一的时空 patch 表示不同分辨率、比例和时长的图像与视频。
3. **HunyuanVideo（2024）**：给出开放的大型视频生成系统，包括 3D VAE、13B Transformer、强文本编码、Flow Matching 和渐进训练。
4. **Wan（2025）**：进一步完善开放模型族、长视频 VAE、训练与推理效率，以及多任务扩展能力。
5. **LingBot-Video（2026）**：用稀疏 MoE 扩大容量，并引入物理奖励、强化学习和动作条件，面向具身智能。

共同趋势是：

- 像素空间 → 潜空间；
- 2D patch → 3D 时空 token；
- 噪声预测 → 连续速度场；
- 单纯追求视觉质量 → 强调物体持续性、物理一致性和动作后果；
- 稠密计算 → 稀疏专家、并行、缓存、量化与蒸馏。

> 核心判断：视频模型正在从“生成看起来真实的内容”转向“预测条件和动作下的未来状态”，但现有模型仍缺乏可靠的因果、物理和闭环交互能力。

## 4. 核心论文精读

### 4.1 DiT：Transformer 成为扩散骨干

**核心内容**

- 在 Stable Diffusion VAE 的 latent 上切 patch，用 Transformer 预测噪声和协方差；
- 比较模型尺寸、patch 大小和四种条件注入方式；
- adaLN-Zero 效果最好：由时间步和类别生成 scale、shift、gate，并把残差门初始化为 0；
- 12 个模型在 40 万步时，前向 GFLOPs 与 FID 的相关系数约为 $-0.93$，说明更多计算通常带来更好生成质量；
- DiT-XL/2 约 675M 参数，256 分辨率、CFG=1.5 时报告 FID 2.27。

#### DiT 的训练与生成流程：务必区分

先记住两个纠正：

1. **训练时先用 VAE Encoder 压缩干净图片，再在 latent 空间加噪**，不是先给 RGB 图片加噪再编码。
2. **纯文本生成时不使用 VAE Encoder**，而是直接从随机 latent 噪声开始；最终只用 VAE Decoder 将干净 latent 还原成 RGB 图片。

##### 训练阶段

```text
干净图片 x₀
  → 冻结的 VAE Encoder
干净 latent z₀（例如 32×32×4，仍保留二维空间结构）
  → 随机采样时间步 t 和高斯噪声 ε
  → zₜ = √ᾱₜ z₀ + √(1-ᾱₜ) ε
带噪 latent zₜ
  → Patchify + 位置编码
latent token 序列
  → DiT，同时显式输入时间步 t 和类别/文本条件 c
预测噪声 εθ（以及本文中的方差参数 Σθ）
  → 与已知真实噪声 ε 计算训练损失
```

关键点：

- $t$ 不是模型内部“记住”的历史状态，而是每次前向都显式输入的噪声强度条件；
- $z_t$ 不是一个失去空间结构的普通一维向量，而是低分辨率特征图，patchify 后才成为 Transformer token；
- 训练 DiT 时通常不需要调用 VAE Decoder，因为噪声 $epsilon$ 本身就是监督标签。

##### 生成阶段

```text
随机 latent 噪声 z_T ~ N(0,I)
  → DiT 预测当前时间步的噪声/方差
  → 采样器计算 z_{T-1}
  → 继续显式输入新的时间步并重复去噪
z_T → z_{T-1} → ... → z₁ → 干净 latent z₀
  → 冻结的 VAE Decoder（只需最后调用一次）
RGB 图片 x̂
```

组件分工：

| 组件 | 作用 |
|---|---|
| VAE Encoder | 训练时把真实图片压缩成 latent；纯文本生成时不用 |
| DiT | 在 latent 空间反复去噪，决定主体、构图、语义和大部分细节 |
| 扩散采样器 | 根据 DiT 的输出和噪声 schedule，把 $z_t$ 更新为 $z_{t-1}$ |
| VAE Decoder | 最后把干净 latent 一次性翻译成 RGB 像素 |

最简记忆：

> **训练：图片 → 编码成 latent → latent 加噪 → DiT 学习预测噪声。生成：随机 latent 噪声 → DiT 多步去噪 → Decoder 输出 RGB 图片。**

补充：图生图任务在生成阶段会使用 Encoder 编码参考图，再把参考 latent 加到某个噪声等级；纯文本生成没有参考图，因此不需要 Encoder。

**局限**

- 仅验证 ImageNet 类别条件，不是文本到视频；
- VAE 仍是卷积结构；
- 最佳结果依赖 CFG 和较长训练。

**建议精读**：§3.1–3.2、Fig.5、Table 1、Fig.6–10，以及附录中的无 CFG 和 VAE 消融。

> 一句话：DiT 证明扩散模型不必依赖 U-Net，可使用具有清晰规模收益的通用 Transformer 骨干。

### 4.2 Sora：统一时空 patch

**核心内容**

- 将图像和视频压入时空潜空间，再划分为 spacetime patches；
- 同一模型支持不同分辨率、宽高比和时长，不强制裁成统一正方形；
- 使用重描述（re-captioning）生成细粒度训练文本，推理时扩写短 prompt；
- 支持文本到视频、图片动画、视频扩展、连接和编辑；
- 随训练计算增加，3D 一致性、长程连贯性和物体持续性出现定性改善。

**如何理解“世界模拟器”**

视觉上符合物理不等于学会了可验证的物理状态转移。报告未公开模型大小、数据规模、优化器、完整损失和系统消融，因此无法区分提升来自数据、模型、训练计算还是 caption 系统。更稳妥的结论是：**Sora 展示了视频模型作为世界模拟器的潜力，但不是可靠世界模型。**

**建议精读**：视觉数据转 patch、规模化 Transformer、可变时长/分辨率/比例、语言理解、模拟能力和失败案例。

> 一句话：Sora 的主要贡献是统一视觉表示与规模化叙事，而不是公开一个可完整复现的新公式。

### 4.3 HunyuanVideo：开放的大型视频系统

**核心结构**

- Causal 3D VAE：约 $4\times8\times8$ 压缩、16 latent 通道；
- 13B Transformer：20 个双流 block + 40 个单流 block，隐藏维 3072、24 个注意力头；
- 双流阶段分别处理文本和视频，单流阶段拼接后联合建模；
- 3D RoPE 分别编码时间、高度和宽度；
- decoder-only MLLM 提供细粒度文本语义，经双向 token refiner 补偿因果注意力，CLIP pooled embedding 提供全局条件；
- 使用 Flow Matching；先做 256/512 图像预训练，再从低清短视频逐步训练到高分辨率长视频，并持续混合图像避免遗忘；
- 使用 CFG 蒸馏，将两次前向压缩为一次，报告约 1.9 倍加速。

#### 精读问答：数据、时序能力与生成机制

**问题一：HunyuanVideo 的分层数据过滤和结构化标注具体如何实现？**

过滤与标注是两个连续步骤。过滤阶段先用 PySceneDetect 将长视频切成单镜头片段，用 Laplacian 清晰度定位清晰起始帧；再以内部 VideoCLIP embedding 的余弦距离去重，并用 k-means 得到约 1 万个概念中心，用于重采样和概念均衡。随后组合 DOVER 审美/技术质量、清晰度模型、光流运动强度、PySceneDetect + TransNet v2 场景边界、OCR 字幕/文字检测，以及 YOLOX 类水印、边框和 Logo 检测器。过滤阈值逐级提高，形成 256p、360p、540p、720p 四级数据；最终 SFT 数据约 100 万条，由人工按色彩、光照、构图、运动速度、动作完整性和运动模糊等维度筛选。

k-means 的作用是把 VideoCLIP 特征相近的片段放进同一近似语义桶，统计训练池中各类内容的频率：常见簇可降采样，稀有簇可提高采样概率，从而防止大量自拍、风景或静态镜头支配梯度，并扩大长尾概念覆盖。聚类编号本身不作为分类标签输入模型，“约 1 万个概念”也不等于 1 万个人工命名类别；它只是由 embedding 和距离定义的采样分桶。其效果依赖 VideoCLIP 表征和聚类数选择，不能保证每个簇语义纯净，也不能替代质量过滤。

**追问：k-means 如何聚类，训练时又如何从聚类结果中取数据？**

设每条视频的 VideoCLIP embedding 为 $e_i$，k-means 先初始化 $K\approx10{,}000$ 个中心 $\mu_k$，然后反复执行：①把每个 $e_i$ 分给距离最近的中心；②把每簇样本的均值作为新中心；直到分配基本稳定。最终每条视频只需保存一个 cluster id，并建立“cluster id → 视频列表”的索引。若 embedding 已做 L2 归一化，欧氏距离排序与余弦相似度排序等价；但论文没有公开聚类距离、初始化方式和迭代细节。

重采样通常分两级：先按目标概率 $q_k$ 选择概念簇，再从该簇内随机取视频。等价地，簇 $k$ 中每条样本可获得权重 $w_i=q_k/n_k$，其中 $n_k$ 是簇大小。若直接按原始数据取样，则 $q_k=n_k/N$，大簇仍会主导；为了平衡，可令各簇近似等概率，或采用 $q_k\propto n_k^\alpha\;(0<\alpha<1)$ 做温度平滑，在多样性与重复采样之间折中。实际系统还会设置最大重复率、质量门槛和簇内去重，防止小簇中的低质量视频被反复抽取。HunyuanVideo 论文只明确说明使用约 1 万个中心进行 concept resampling and balancing，没有公布 $q_k$、$\alpha$、配额或在线/离线采样实现，因此这些公式是常见实现，而非论文已确认配置。

标注阶段由内部 VLM 生成 JSON 结构化 caption，包括短描述、密集描述、背景、风格、景别、光照和氛围，并加入来源、质量等元数据；另用分类器识别 14 类镜头运动。训练时对这些字段做 dropout、重排和组合，生成不同长度与形式的 caption，减少模型只适应固定模板。论文未公开各过滤器阈值、内部模型权重和完整数据量，因此只能复现思路，不能严格复现数据集。

**问题二：视角变化、连续动作等视频能力只是扩大参数和数据后自动涌现的吗？**

不是单纯由规模自动产生。规模扩大提供了表达复杂时空规律的容量，但能力还来自明确的结构偏置和监督：视频数据本身提供跨帧变化；Causal 3D VAE 保留时间结构；3D patch、Full Attention 和 3D RoPE 让模型联合建模时间、高度和宽度；结构化 caption 与镜头分类器显式标注动作和视角变化；运动过滤、高动态 SFT 及“短视频 → 长视频、低清 → 高清”的课程训练强化动态能力。更准确的说法是：**规模提高能力上限，数据决定学什么，结构决定如何表示，训练策略决定能否稳定学到。** 即使三者同时扩大，也不保证可靠物理规律，穿透、形变和因果错误仍可能出现。

**追问：相比普通图片模型，视频模型为什么能学会视角变化和连续动作？**

普通图片样本只有 $T=1$，最多让模型从大量静态图片中学到“物体从不同角度可能长什么样”，却没有证据判断某个视角之后应如何连续变化；同一张静态图对应的未来动作也不是唯一的。视频样本则把相邻帧的先后顺序、位移、遮挡、形变和运镜轨迹直接记录下来，形成隐式时序监督。训练时整段视频 latent 被联合加噪，模型若想正确恢复每个时空 token，就必须利用其他帧的信息，学习 $p(x_{1:T}\mid c)$ 中的跨帧相关性；镜头运动 caption 又提供了显式语义监督，使这些变化可被文本控制。

渐进训练解决的是“同时学习太多难点会不稳定”：图像预训练先学习物体、纹理和构图；低清短视频以较少 token 学局部运动；低清长视频再学长程一致性和场景变化；最后用高清长视频学习细节，同时继续混入图片以避免视觉语义退化。因此，视频能力来自**视频序列提供的时序证据 + 能表示时间的架构 + 由易到难的优化课程**，而不是训练策略从静态图片中凭空创造运动规律。

**问题三：训练时输入文本、图片和视频，为什么推理时模型能生成连贯后续帧？**

训练并不是把“文字 → 图片 → 视频”作为一条序列反复输入。每个样本通常是 caption 与一张图片或一段完整视频的配对；图片被视为单帧视频。Flow Matching 对整段视频 latent 同时加噪，并让 DiT 预测全部时空 token 的速度场。T2V 推理时先建立目标时长和分辨率对应的完整随机 latent，再多步联合去噪整段视频；连续性来自模型学到的跨帧统计关系以及时空 token 的联合注意力，而不是像语言模型那样逐帧生成下一帧。Causal 3D VAE 负责时序压缩，不代表 DiT 是逐帧自回归模型。

真正的图生视频续写需要额外条件。论文的 I2V 模型直接用参考图 latent 替换第一帧 latent，并将其时间步设为 0，其他帧仍按 T2V 方式加噪；同时用 MLLM 提取参考图语义 token，与视频 token 一起做 Full Attention。因此模型是在“首帧外观 + 文本语义”的约束下补全其余帧。论文还用首尾帧条件实现插帧。超出训练时长的任意长期续写则没有被证明可靠，3D RoPE 的外推能力也不等于稳定的无限视频生成。

**问题四：固定帧数的视频如何做时间压缩？时空 tiling 又是什么意思？**

时间压缩不是每隔 4 帧机械保留 1 帧。3D VAE 用带时间步幅的可学习 3D 卷积，把局部多帧中的外观、位移和变化编码进通道更丰富但时间位置更少的 latent。输入 $(T+1)\times3\times H\times W$ 被编码为 $(T/4+1)\times16\times H/8\times W/8$；例如 9 帧变为 3 个 latent 时间位置，decoder 再由这 3 个位置重建 9 帧。latent 位置不是某一张原始帧，而是局部时空信息的压缩摘要。该过程必然有损：缓慢、可预测的变化较容易重建，快速运动、细小物体、闪烁和突然切换等时间高频信息更容易丢失，因此时间压缩率是 DiT 成本与运动保真度之间的折中。

时空 tiling 不减少帧数，而是为避免 VAE 编解码长高清视频时显存溢出，把 $T\times H\times W$ 张量切成相互重叠的三维小块，例如先切多个重叠时间窗口，每个窗口再切多个重叠空间区域；每块分别经过同一个 VAE，最后在重叠区做线性加权融合。重叠是为了给卷积边界提供上下文并减轻空间接缝和时间跳变。由于分块推理与整段训练存在分布差异，作者又在微调时随机启用/关闭 tiling，使 VAE 同时适应两种路径。论文没有公开 tile 尺寸、重叠宽度和融合权重；而且 §4.1.2 的 tiling 只解决 VAE 编解码显存，并不表示 13B DiT 也按同样方式分块。

**问题五：MLLM + CLIP、双流到单流、Refiner、时间调制、3D RoPE 和 FFN 分别为何存在？**

模型权重可以视为黑盒，但架构接口通常按信息类型和失败模式设计。视频 token 数量巨大且带噪，文本 token 少且语义密集；若从第一层完全共享参数和注意力，视频 token 可能稀释文本信号，共享 Norm/MLP 也要同时适应两种分布。双流阶段让两种模态先用各自参数提取和调制特征，单流阶段再拼接做深度融合，是“模态专用处理 + 跨模态交互”的折中，并继承 FLUX 的 dual-stream to single-stream 设计。全单流理论上表达能力更自由，但连接更多不等于更易优化或参数使用更有效；本文没有给出完整对照消融，不能声称混合结构已被严格证明最优。

MLLM 输出一串细粒度 token，擅长主体关系、描述和指令理解；CLIP pooled feature 是经过图文对齐训练的稳健全局摘要。两者分别承担局部语义序列与全局条件。decoder-only MLLM 的隐藏状态受因果 mask 限制，前方 token 看不到后文，因此 Token Refiner 对 MLLM 特征再做无因果 mask 的双向 self-attention，使每个 token 结合整句上下文；其基本形式仍是 Norm → Multi-head Attention → 残差 → FFN。论文没有公开 Refiner 的层数、完整配置和单独消融。

**追问：为什么 CLIP 文本特征与时间相加为 $y$，而 MLLM 特征作为 token 输入？block 图为何没有画 $y$？**

同一 caption 被编码成两种形状不同的条件：CLIP 路径得到每个样本一个 fixed-size pooled vector，时间路径也得到一个 fixed-size vector，二者经 MLP 对齐维度后可相加为全局条件 $y=e_{\mathrm{CLIP}}+e_t$，再广播到各层产生 Scale、Shift 和 Gate；这样所有视频/文本 token 都共享“当前噪声阶段 + 全局语义”。MLLM + Refiner 则输出长度为 $L$ 的 token 序列 $H\in\mathbb{R}^{L\times d}$，每个位置承载不同词和关系，若直接池化后与时间相加会丢失细粒度结构，因此它作为绿色文本 token 进入双流，之后与视频 token 在单流中融合。

Figure 8 的总览箭头明确把 $y$ 输入整个 DiT block stack，正文也说明 CLIP 全局特征被整合进双流和单流 block；右侧 block 模板为避免重复连线，没有再画 $y$ 到每个 Scale & Shift / Gate 的箭头。图中的这些调制量通常由各 block 对 $y$ 做线性/MLP 投影得到，最终输出前的 Modulation 也使用全局条件。论文没有展开逐层投影公式，因此可确定的是信息路径，不能仅凭示意图补全共享方式等实现细节。CLIP 与时间也可以拼接而不是相加；相加是维度固定、参数较省的标准条件融合选择，并非数学上唯一方案。

**追问：为什么仅靠 Scale、Shift 和 Gate 就能注入时间与全局文本条件？**

它们通常不是三个标量，而是每个 block、每个通道各自的向量。对 $d=3072$ 的隐藏状态，一组 $(s,b,g)$ 就可包含约 $3d$ 个条件相关控制量，Attention 与 MLP 分支、文本与视频流还可分别投影；60 个 block 层层使用后，控制自由度很高。条件化残差可写成 $h_{l+1}=h_l+g_l(y)\odot F_l((1+s_l(y))\odot\mathrm{Norm}(h_l)+b_l(y))$：Scale 选择/抑制特征通道，Shift 改变激活阈值和内容基准，Gate 控制本层更新是否写入残差。由于它们会进一步改变 Q/K/V、Attention 和 FFN 的输入，逐层复合后相当于由 $y$ 选择一族连续变化的子网络，而非只在输出上乘几个系数。

这种全局调制适合所有 token 共享的噪声阶段和主题摘要，但不足以独立表达复杂 prompt 中的逐词关系，所以 HunyuanVideo 仍让 MLLM token 进入 Attention。时间/CLIP modulation 与 MLLM token attention 是互补接口，不是前者单独承担全部条件控制。

扩散时间 $t$ 是连续标量，先用正弦/余弦频率映射为向量 $[\sin(\omega_i t),\cos(\omega_i t)]$，再经 MLP 得到时间条件。CLIP 全局向量扩维后与其相加。Modulation 将该条件映射为每层的 scale、shift 和 gate，例如 $h'=(1+s)\odot\mathrm{Norm}(h)+b$，再令 $h\leftarrow h+g\odot\mathrm{Attention}(h')$。它告诉所有 block 当前噪声强度和全局语义，使同一网络在高噪声时侧重构图、低噪声时侧重细节；它不是 token 的位置编码。

**追问：时间 $t\in[0,1]$ 已经简洁且唯一，为什么还要正弦编码？**

原始标量 $t$ 在信息论上已经足够，正弦编码不增加新信息；问题在于网络是否容易从一维输入学到复杂的条件函数。若直接线性投影 $t$，各通道起初只能得到不同斜率的仿射函数；即使后接 MLP 理论上可逼近任意函数，也存在偏向低频、平滑函数的优化倾向，而去噪行为可能在某些噪声区间快速变化。多频率 $[\sin(\omega_i t),\cos(\omega_i t)]$ 预先提供从粗到细的基函数，使模型更容易区分相近时间、表达非线性变化并在连续 $t$ 上插值。它是可学习性的坐标变换，而不是唯一性编码；直接使用 $t$、learned embedding 或 log-SNR 也可行，优劣需靠消融确定。

3D RoPE 作用于注意力的 $Q,K$。每个 head 的 128 维被拆成 $(d_t,d_h,d_w)=(16,56,56)$，分别使用 token 的时间、高度和宽度坐标。对某一坐标 $p$ 和二维通道对 $(a,b)$，执行旋转 $[a',b']^\top=R(p\omega)[a,b]^\top$，其中 $R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$；$Q,K$ 使用相同规则，而 $V$ 不旋转。由于 $R(p)^\top R(q)=R(q-p)$，注意力点积能感知相对位移。论文没有详细说明单流阶段文本 token 如何分配三维坐标，不能自行补全。

FFN dimension 不是由公式唯一求出，而是超参数。本文模型维度 $d=3072$，沿用常见的 4 倍扩展比，取 $d_{ff}=4d=12288$。典型 FFN 对每个 token 做 $3072\rightarrow12288\rightarrow3072$；中间升维让逐 token 非线性变换拥有更大容量，代价是参数和计算近似随 $2dd_{ff}$ 增长。Table 2 中 $24\times128=3072$ 则来自 24 个注意力头、每头 128 维。

**追问：为什么同时使用 MLLM、CLIP 与 Refiner？Figure 10 的横纵轴分别是什么？**

MLLM 输出一串 token，保留“谁做什么、修饰谁、动作顺序”等细粒度关系；CLIP 取最后一个非 padding token 作为一个全局摘要，和时间 embedding 相加后调制各层。两者不是重复编码：前者以 token 参与跨模态融合，后者以向量稳定地向所有层提供全局语义与当前去噪阶段。MLLM 是 decoder-only，因果 mask 使前面的词看不到后面的词；Refiner 在其输出后使用双向 self-attention，让每个词都能结合整句，再送入视频 DiT。它不重新理解原始文本，而是消除 MLLM 特征的单向上下文缺口。论文报告组合更好，但未给出三者逐项消融，不能量化各自增益。

Figure 10 的横轴始终是训练计算量 $C$（PetaFLOPs），纵轴随子图改变，故不是两个自变量： (a)/(d) 为训练 loss；(b)/(e) 为在该计算预算下 loss 最低的模型参数量 $N_{opt}$；(c)/(f) 为对应的最优训练 token 数 $D_{opt}$。你的直觉是对的：原始实验中 $C$ 大致由模型规模 $N$ 和训练 token 数 $D$ 的乘积决定，三者并不独立；作者先改变模型大小和训练时长，得到各条曲线，再在“总算力预算已给定”的规划视角下，把 $C$ 作为横轴。每条彩色 loss 曲线代表固定模型规模，曲线交点表示“算力较小时小模型更合算、算力较大时大模型更合算”；取各算力下最低 loss 的灰色 envelope，再拟合 $N_{opt}=a_1C^{b_1}$、$D_{opt}=a_2C^{b_2}$。上排先用图像模型测量，下排以其最佳 checkpoint 初始化视频模型；13B 是据下排规律并兼顾推理成本选出的折中，不是公式唯一推出的答案。还要注意，规模律实验用的是 T5-XXL + cross-attention 的 DiT-T2X，而非最终 MLLM 双流到单流架构，故它是选型参考，不是最终系统的严格定律。

**追问：既然没有 $L(C,N,D)$，$N_{opt}$ 和 $D_{opt}$ 如何得到？**

它们由经验包络而非解析推导得到。作者训练多个固定规模 $N_j$ 的模型，并在多个训练进度记录 $(C,L)$；每条彩线就是 $L(C\mid N_j)$。对某一预算 $C_i$，在可用的离散模型中选 loss 最小者 $N_i^*$，并读取该 checkpoint 已训练的 token 数 $D_i^*$；灰点即 $(C_i,N_i^*,D_i^*)$。最后只对这些灰点在 log-log 坐标做幂律拟合，得到 $N_{opt}(C)$ 与 $D_{opt}(C)$。因此它回答的是“在已测区间、候选模型和训练配方内，预算 $C$ 应怎样分配”，不是从一个公开损失函数对 $N,D$ 求偏导得到全局最优；离散模型档位、拟合误差和训练配方都会影响结果。

**批判：Figure 10 的“scaling law”证据不如 LLM scaling law 完整。**

论文没有给出或拟合类似 $L(N,D)$（结合 $C\approx kND$ 后可求计算最优）的显式指数损失关系，只展示固定模型大小下的 $L(C\mid N)$ 曲线，并从离散曲线包络回归出 $N_{opt}(C)$、$D_{opt}(C)$。因此，(b)(c)(e)(f) 不是验证独立变量间因果关系的二维实验图：横轴 $C$ 本就大致由 $N,D$ 决定，纵轴只是每个预算下从包络点读出的“经验最优分配”。它们对实际选模型仍有有限意义，但不能单独证明跨规模、跨数据或最终架构都成立的通用指数律；尤其本文未报告拟合误差、完整损失面或对最终 MLLM 架构的验证。组会可概括为：**它提供了经验化的 compute allocation rule，而非像 Chinchilla 一类工作那样更可检验的完整 scaling-law 模型。**

**追问：高质量视频稀缺，为何不在预训练一开始只使用它们？**

“高质量”不能替代规模、覆盖和多样性。预训练首先要学大量物体、场景、动作和文本对应；若只反复使用稀缺精品，概念覆盖变窄、样本重复率升高，容易过拟合其摄影风格和运动分布。低分辨率早期阶段也主要学习低频语义与基本运动，精品视频的高频画质优势难以完全利用。更合理的策略是：大规模过滤后数据建立通用视觉/时序先验，随后逐步提高分辨率、时长和质量门槛，再用人工筛选的高质量、高动态子集微调审美、连续动作和角色动画。高质量样本并非必须早期排除，通常可按权重或分桶混入；但 HunyuanVideo 未公开各阶段的质量配额、重复率或采样权重，不能把上述顺序误说成论文已验证的唯一最优方案。

**追问：步数固定时，time-step shifting 与 linear/quadratic scheduler 的计算量和耗时是否相同？**

基本相同。二者都以相同的 $Q$ 个时间点调用同一个模型，每次前向的分辨率、token 数和网络结构不变；shifting 只把 $t$ 映射为 $t'=st/[1+(s-1)t]$，scheduler 的标量计算可忽略。因此它是**相同预算下改善质量**，不是减少 FLOPs 的加速。少步带来的主要加速来自把 $Q$ 本身减小；CFG 蒸馏则是另一件事，它把每步通常需要的条件/无条件两次前向近似压为一次，论文报告约 $1.9\times$ 加速。实际端到端耗时还可能受实现、缓存和通信影响，但不会因这两种 scheduler 的公式本身产生显著差异。

**追问：为什么把 guidance scale $w$ 输入学生模型后，一次前向能代替 CFG 的两次前向？**

教师先计算 $v_u=f_\theta(x_t,t,\varnothing)$ 与 $v_c=f_\theta(x_t,t,c)$，并以 $v_T=v_u+w(v_c-v_u)$ 构造监督目标。这个目标对给定 $(x_t,t,c,w)$ 是确定函数；训练时学生 $v_\phi(x_t,t,c,w)$ 直接回归 $v_T$，因而把“无条件基线 + 条件修正 + $w$ 加权”的效果编码进自身参数。推理时学生不会再显式调用空条件分支，而是用一次前向近似输出该组合结果。随机采样 $w\in[1,8]$ 使同一学生可服务多个 guidance scale；它不是数学恒等变形，而是有误差的知识蒸馏，仍需额外训练，且在未覆盖的 $w$ 或 prompt 上未必完全等同教师。论文未公开 $w$ embedding 注入各层的具体实现。

**追问：教师-学生架构是为了什么，原理是什么？**

教师-学生不是新的 DiT 主干，而是“用慢函数教会快函数”的蒸馏训练关系。本论文中教师和学生结构、超参数相同，学生还由教师权重初始化；差别在于教师部署 CFG 时每步要算两次，学生只算一次。原始数据没有“CFG 后的正确速度”标签，故先用高质量但昂贵的教师输出 $v_T$ 作为软标签，再训练学生拟合 $v_T$。因为 $v_T$ 对 $(x_t,t,c,w)$ 是确定映射，学生可把无条件基线及其随文本、时间和 $w$ 的变化隐式储存在参数中；推理时将训练期的两次计算替换为一次近似函数计算。代价被转移到额外蒸馏训练，且存在逼近误差；“学生”并不必然更小，本例的加速来自少一次前向而非缩小网络。

这里的“两次压为一次”专指每个采样步的两次主干前向：$f_\theta(x_t,t,\varnothing)$（空文本）和 $f_\theta(x_t,t,c)$（真实文本），不是把两个不同模型物理拼接。常规 CFG 必须拿到两份输出后才能相减、乘 $w$、相加；即使实现中把二者拼进同一 batch，主干 FLOPs 仍约为两份。蒸馏后改为一次 $f_\phi(x_t,t,c,w)$，直接近似最终组合 $v_T$；这是用额外训练换掉第二次部署前向，不是对教师计算图的精确化简。

**价值与边界**

HunyuanVideo 把 Sora 的高层概念落成较完整的开放系统，并讨论数据、VAE、文本编码、scaling law、训练课程和分布式训练。但其 scaling law 来源于特定数据、损失和训练区间，不应当作跨模型普适定律。

**建议精读**：§4.1–4.5、§5.1–5.2；工程汇报再读 §5.3。

> 一句话：大型视频模型不是简单放大 DiT，而是 VAE、文本表征、渐进训练和推理优化的联合设计。

### 4.4 Wan：开放模型族与效率

**关键技术**

- 127M Wan-VAE：causal Conv3D、RMSNorm 和 feature cache，可分块编码/解码长视频；
- 提供 1.3B/14B 视频 DiT；self-attention 建模时空关系，cross-attention 注入 umT5 文本；
- 时间调制 MLP 跨 block 共享，每层仅学习不同 bias，把更多参数预算用于加深网络；
- 使用 Rectified Flow / Flow Matching，并从图像逐步联合训练到 720p、约 5 秒视频；
- 长序列训练使用 FSDP、二维 context parallel、activation offload 和 checkpointing；
- 推理侧使用 diffusion cache、FP8 GEMM 和低比特 attention。

**评估边界**

论文报告 Wan14B 在 Wan-Bench 上为 0.724、Sora 为 0.700，VBench 总分为 86.22%。但 Wan-Bench 由作者设计，部分维度依赖检测器或 MLLM，商业模型版本、采样设置和 prompt 重写也会影响公平性，不应把单一总分视为绝对排名。

**建议精读**：§4.1–4.2、§4.7.2；研究大模型系统时再读 §4.3–4.4。

> 一句话：Wan 的贡献是把视频 DiT 做成高质量、开放、可训练、可推理和可扩展的完整模型族。

### 4.5 LingBot-Video：稀疏世界模型与具身智能

**目标变化**

互联网视频偏重美学与创意，缺少机器人交互和精确物理动态。LingBot-Video 因此从架构、数据和后训练三个方向，把视频生成推进到动作条件下的未来预测。

**关键技术**

- Sparse MoE：保留共享专家，并为每个 token 路由 Top-K 专家，以总容量换取专业化，同时控制激活计算；
- 代表配置 13B-A1.4B：总参数约 13B，每个 token 激活约 1.4B；
- 使用 online bias correction 和 sequence-wise auxiliary loss 改善负载均衡；
- 数据侧使用 profiling、世界知识拓扑、结构化 caption 和 curriculum；
- 后训练奖励同时考虑审美、文本一致性、物理合理性和任务成功；
- 使用 GRPO 式强化学习和 negative-aware finetuning，惩罚穿透、复制和结构变形等失败；
- Action-to-Video 将初始状态和未来机器人动作对齐到 latent 时间轴，预测未来视觉轨迹；
- 使用改进 DMD2 做少步蒸馏。

**边界**

论文报告 RBench 均分 0.620，Physics-IQ Verified I2V 为 40.4。结果具有竞争力，但绝对分仍有限；部分大规模曲线只覆盖早期训练，且内部 benchmark 和奖励可能偏向本模型。

**建议精读**：§2.2–2.4、§5.2–5.4、§6.2–6.4。

> 一句话：MoE 扩大容量，物理奖励与动作条件则把“视觉逼真”推进到“对机器人有用的未来预测”。

### 4.6 MeanFlow：把局部速度压缩成跨区间预测

**论文**：*Mean Flows for One-step Generative Modeling*（arXiv:2505.13447，2025）。

**核心问题**：标准 Flow Matching 只会回答“此刻的瞬时速度是多少”，因此推理时需要反复查询。MeanFlow 改为学习任意区间 $[r,t]$ 的平均速度，使一次预测可以跨过整段。

**关键恒等式**：

$$
u(r,t)=v(t)-(t-r)\frac{du(r,t)}{dt}.
$$

训练时随机抽取长短不同的 $(r,t)$，用 JVP 计算沿轨迹的总导数，再用 stop-gradient 构造自一致目标。短区间边界 $u(t,t)=v(t)$ 提供锚点，大量不同区间的一致性共同约束长区间预测。

**边界**：一步跨全程没有中途纠偏，因此速度和质量之间仍有权衡；两到四步 MeanFlow 可用更多 NFE 换取误差修正。它学习区间净位移，不等于把底层轨迹几何上“修直”。

> 一句话：老师不直接给整月平均消费，而是给每天消费以及“总额必须等于每天之和”的规则；练过足够多长短区间后，模型学会直接报出任意时段的平均值。

### 4.7 Generative Modeling via Drifting：把迭代生成移到训练阶段

**论文**：Mingyang Deng、He Li、Tianhong Li、Yilun Du、Kaiming He，*Generative Modeling via Drifting*（arXiv:2602.04770v2，2026-02-06）。

**核心问题**：扩散与流模型把分布的演化放在推理时；Drifting 则让生成器的 pushforward 分布 $q_\theta=f_{\theta\#}p_\epsilon$ 在 SGD 训练中不断演化，最终得到一次映射 $f_\theta(\epsilon)$。

**方法**：对当前生成样本，真实样本作为 positive 产生核加权吸引，当前生成样本作为 negative 产生排斥；两者之差形成 drifting field。当 $q_\theta=p_{\text{data}}$ 时，反对称的吸引与排斥抵消，到达 $V=0$ 的平衡。损失让当前生成输出追赶 stop-gradient 目标 $x+V(x)$。

**与对比学习的关系**：它确实使用 positive / negative 与类 InfoNCE 的 softmax 核权重，但目标不是学表示，而是计算生成样本的移动方向并训练一步生成器。

**与 Score 的关系**：两者都可被画成向量场，但 Drifting field 不是 $\nabla_x\log p_t(x)$，也不需要按多个扩散时刻学习 score。它的方向由当前的 $p_{\text{data}}$ 和 $q_\theta$ 共同构造，并且在训练后不再于推理时查询。

**证据与边界**：论文在 ImageNet $256\times256$ 报告 latent-space 1-NFE FID 1.54、pixel-space FID 1.61。这些是论文自报结果；方法对特征编码器、批内正负样本数、核温度与归一化很敏感，原文也报告在 ImageNet 上不使用特征编码器时未能训练成功。

#### 精读问答：为什么已有 MeanFlow，还要 Drifting？

**问题一：MeanFlow 理论上也能一步生成，为什么还要开发 Drifting？**

两者的**推理目标相同**：都希望只调用一次网络就从噪声得到样本；但达到目标的训练原理不同。

| 方法 | 训练时学什么 | 一步时怎么做 |
|---|---|---|
| MeanFlow | 扩散 / Flow Matching 路径上任意区间的平均速度 $u(z_t,r,t)$ | 令区间从噪声端直接跨到数据端，预测一次平均速度并更新 |
| Drifting | 直接训练映射 $f_\theta(\epsilon)$ 的输出分布 $q_\theta$ 向真实分布 $p_{\text{data}}$ 靠近 | 直接输出 $f_\theta(\epsilon)$；没有时间步、去噪轨迹或 ODE 积分 |

所以 MeanFlow 是“**保留扩散 / 流的路径，再把全程压缩为一步**”；Drifting 是“**连这条路径也不预先定义，直接让 SGD 期间的生成分布演化到数据分布**”。开发 Drifting 的意义不是证明 MeanFlow 不能一步，而是探索另一条原生一步路线：不依赖已知的扩散 SDE/ODE、噪声时刻或轨迹一致性目标。代价是它目前强依赖特征空间、核函数和大批量真/假样本；在复杂文本到图像或视频上的可扩展性尚未由本文证明。

**问题二：作者如何跳出“生成就是逐步去噪”的思路？**

去噪不是生成模型必须遵守的定律，而是把难的分布映射拆成许多容易小更新的一种成功设计。作者先退回到更基本的目标：找一个函数 $f$，使高斯先验经它映射后的分布满足 $q=f_{\#}p_\epsilon\approx p_{\text{data}}$。随后把“谁来逐步改变分布？”从推理阶段换成训练阶段：参数每做一次 SGD 更新，固定噪声 $\epsilon$ 的输出就从 $f_i(\epsilon)$ 变为 $f_{i+1}(\epsilon)$，整个 $q_i$ 已经在演化。

接着只需构造一个合理的更新方向 $V_{p,q}(x)$：当 $q=p$ 时必须为零，$q\ne p$ 时应推动生成样本朝真实数据移动。本文用真实样本的吸引减去生成样本的排斥，并把 $x+V(x)$ 作为 stop-gradient 目标训练生成器。也就是说，**迭代没有消失，而是从采样时的“逐步去噪”转移为训练时的“逐步改参数”**。这是一种重新表述，不代表它已经摆脱所有迭代成本或给出了全局收敛保证。

**问题三：Mean Shift 是什么算法，为什么出现在这里？**

Mean Shift 是一个经典的非参数聚类 / 寻找密度峰值算法。给定一堆样本，对当前位置 $x$，它先用核函数给附近样本更大权重，再把 $x$ 移向这些样本的加权平均：

$$
m(x)=\frac{\sum_i k(x,y_i)y_i}{\sum_i k(x,y_i)},\qquad
\Delta x=m(x)-x.
$$

不断重复后，点会爬向数据更密集的区域；它不需要事先规定簇数。Drifting 借用的正是这个“局部加权平均的移动方向”：$V_p^+(x)$ 把生成样本拉向附近的真实样本，$V_q^-(x)$ 指向附近的其他生成样本；二者相减 $V=V_p^+-V_q^-$ 后，既有“靠近真实数据”的力，也有“不要挤在已有生成样本处”的力。若真、假分布相同，这两个平均方向对称抵消，得到平衡 $V=0$。

**带读第一步：先只读 §3.1--§3.2 的三件事。**

1. 记号：$\epsilon\sim p_\epsilon$，$x=f_\theta(\epsilon)$，输出分布记为 $q_\theta=f_{\theta\#}p_\epsilon$；这里的 $\#$ 只表示“把一个分布经函数映射到另一个分布”。
2. 关键换位：Diffusion 在推理时让 $x_t\to x_{t-1}$；Drifting 在训练迭代间让同一噪声的输出 $f_i(\epsilon)\to f_{i+1}(\epsilon)$。
3. 先检查平衡条件：反对称性 $V_{p,q}=-V_{q,p}$ 保证 $p=q\Rightarrow V=0$；但反过来 $V=0\Rightarrow p=q$ 并不天然成立，这是论文随后必须用核设计和附录条件来补强的薄弱点。

读完这三点后，再读 §3.3 的式 (8)--(12)：它具体把 $V$ 实现成 Mean Shift 式的“真实吸引 - 生成排斥”。

#### 高维覆盖与局部核：两个必须澄清的问题

**1. 纯噪声不需要靠运气“命中”数据流形。** $z$ 是生成器的输入编码，$x=f_\theta(z,c)$ 才在图像/latent 空间。确定生成器对应的转移核可写为：

$$
T_\theta(dx\mid z,c)=\delta_{f_\theta(z,c)}(dx),
\qquad
q_\theta=f_{\theta\#}p_z.
$$

训练目标是使 pushforward 分布 $q_\theta$ 匹配 $p_{\text{data}}$，而不是让 $z$ 在输出空间随机命中一个极小流形。训练与推理使用同一高斯先验，模型主要学习其 typical set 上的映射。

**但论文没有证明满射或全局收敛。** $q=p\Rightarrow V=0$ 由反对称性保证；反向的 $V\approx0\Rightarrow q\approx p$ 只在特定核和非退化条件下有可辨识性启发。逐点满射也比概率分布匹配更强，并非生成建模所必需。

**2. 论文的 $K$ 不是“真图局部扰动—恢复核”。** 训练每轮都先抽完整先验 $z\sim p_z$，生成当前输出 $x=f_\theta(z,c)$；$K$ 只负责在输出特征空间衡量 $x$ 与真/假样本的相似度并构造 drift。很多轮局部输出反馈通过共享参数累积，才训出全局一步映射；推理时没有“从遥远噪声沿 $K$ 移动回来”的过程。

若当前生成特征与真实特征都距离遥远，核可能变得平坦而缺乏区分度。论文用预训练特征编码器、特征/drift 归一化、多尺度、多温度、大量正负样本和样本队列缓解这一问题。这是工程设计而非全局吸引子定理；论文在 ImageNet 上不使用有效特征编码器时未能成功训练，正说明该局限真实存在。

#### 条件是怎样选中目标分布的

prompt / 类别 $c$ 不指向某张唯一目标图的坐标，而是定义条件分布 $p_{\text{data}}(x\mid c)$。Drifting 训练时对每个条件分别比较：

$$
y^+\sim p_{\text{data}}(\cdot\mid c),
\qquad
x=f_\theta(z,c)\sim q_\theta(\cdot\mid c),
$$

并构造 $V_c=V^+_{p(\cdot\mid c)}-V^-_{q_\theta(\cdot\mid c)}$。真正“漂移”的是训练迭代之间的条件输出分布：

$$
q_{\theta_0}(\cdot\mid c)
\to q_{\theta_1}(\cdot\mid c)
\to\cdots\to p_{\text{data}}(\cdot\mid c).
$$

推理时不再用真实样本建场，也没有样本沿场积分的过程；只计算 $x=f_\theta(z,c)$。所以 Drifting 更像“训练时按不同目标街区校准一台传送机”，而不是“推理时用 prompt 搜索一张图再流过去”。

**论文边界**：本文大规模实验主要是 ImageNet 类别条件，positive 来自同类真实样本。任意长文本 prompt 还需要文本编码、语义 positive/negative 抽样与条件注入设计，不是这篇论文已经完整验证的部分。

> 一句话：Score 是推理时反复查询的密度坡度；Drifting 是训练时由真/假样本构造的吸引−排斥力，它把反复演化留在 SGD 中，推理时只跑一次生成器。

### 4.8 Improved Mean Flows：让 MeanFlow 的批改标准更稳定，CFG 更灵活

**论文**：Zhengyang Geng、Yiyang Lu、Zongze Wu、Eli Shechtman、J. Zico Kolter、Kaiming He，[*Improved Mean Flows: On the Challenges of Fastforward Generative Models*](https://arxiv.org/abs/2512.02012)（arXiv:2512.02012v2，2026-05-09）。

**核心问题一：原 MeanFlow 的目标自引用且高方差。** 原方法预测平均速度 $u_\theta$，但真实 $u$ 不可直接得到，只能用包含 $u_\theta$ 自身的 JVP 构造伪目标。而 JVP 切向量使用单对数据—噪声的 conditional velocity $v_c=e-x$，同一中间点对应的 $v_c$ 方差很大，会被 JVP 放大。

**改进目标：$u$-prediction，$v$-loss。** iMF 将 MeanFlow 恒等式写为：

$$
v=u+(t-r)\frac{du}{dt}.
$$

网络仍输出 $u_\theta$，但先组合出隐含瞬时速度：

$$
V_\theta
=u_\theta+(t-r)
\operatorname{JVP}_{\operatorname{sg}}(u_\theta;v_\theta),
$$

再与已知 FM 目标 $e-x$ 回归：

$$
\mathcal L_{\text{iMF}}
=\mathbb E\|V_\theta-(e-x)\|^2.
$$

$v_\theta$ 可直接用边界 $v_\theta(z_t,t)=u_\theta(z_t,t,t)$，也可使用训练期 auxiliary $v$-head。这使 JVP 的切向量是当前状态的 marginal velocity 预测，而不是高方差的单对 $e-x$。

> 一句直觉：模型仍回答“整段平均速度 $u$”，但老师不再用学生自己猜的 $u$ 伪标签批改；而是把学生的 $u$ 换算成隐含瞬时速度，再与手中已知的 $e-x$ 对答案。

**核心问题二：原 MeanFlow 的 CFG 强度需预先固定。** iMF 将 guidance scale $\omega$ 以及 CFG 生效区间作为显式输入条件：

$$
u_\theta=u_\theta(z_t\mid r,t,c,\omega,t_{\min},t_{\max}).
$$

训练时随机抽 $\omega$，推理时可在同一 1-NFE 模型上自由调整，无需重训或做两次 CFG 前向。

**条件架构**：将 $(r,t)$、类别 $c$、CFG 强度与生效区间分别转换为多个 in-context tokens，与图像 latent tokens 拼成 Transformer 序列。论文移除 adaLN-zero 后，同宽度/深度的 Base 模型从 133M 降到 89M 参数。

**没有改变的东西**：iMF 仍然预测 $u$、仍使用 JVP 和 stop-gradient，仍以 $z_0=z_1-u_\theta(z_1,0,1)$ 做一步生成；它不是普通 FM，也不是蒸馏。

**结果与边界**：论文 v2 报告 ImageNet $256\times256$ 上 1-NFE FID 1.72，原 MeanFlow 基线为 3.43，并从零训练。这是类别条件图像实验，尚不表示同等收益已在大规模文本到视频中得到验证。

> 一句话：iMF 不改“一次预测整段平均速度”的目标，只是把批改标准换成稳定的 $v$-loss，再把 CFG 强度做成可调条件。

可以归纳出八条跨论文结论：

1. 视频生成的首要瓶颈常是时空 token，而不只是参数量。
2. 视频 VAE 的压缩率和重建质量决定了 DiT 的扩展上限。
3. 条件注入从类别 adaLN 发展到文本 cross-attention、双流/单流融合和动作调制。
4. caption 与 prompt rewrite 会改变条件分布，是模型能力的一部分。
5. Flow Matching 因速度场目标和 ODE 采样简洁，成为大视频模型常用方案。
6. CFG 有效但昂贵，因此缓存、蒸馏和学习式 guidance 很重要。
7. 开放模型的竞争已扩展到数据、VAE、主干、并行、推理、评测和应用的完整系统。
8. 世界模型不能只以视觉逼真定义，还需验证动作条件下的未来预测、因果和物理一致性。

### 当前困惑与讨论

**困惑一：论文中的复杂 block，以及 Norm、Scale、门控、条件调制等结构，是怎样设计出来的？做 research 时需要自己设计吗？**

一般不需要从零发明。研究者通常先复用成熟骨架，再根据明确的失败现象做小改动：训练不稳定就检查 Norm 和初始化；条件控制不足就尝试 adaLN、Cross-Attention 或门控；信息传递困难就调整残差和 Scale；计算太贵再改 Attention 或稀疏结构。像 adaLN-Zero，本质上也是把 LayerNorm、条件调制、残差门控和零初始化这些已有零件合理组合起来。真正的研究设计通常是：**发现问题 → 提出最小结构改动 → 用消融实验验证每个零件是否必要**，而不是先堆一个复杂 block。

可执行的架构实验流程是：①选一个已复现且稳定的 baseline；②用指标和样例定位单一问题，如文本对齐差、长程漂移、显存过高或梯度不稳；③写出可证伪假设，例如“共享早期 block 导致模态梯度冲突”；④只改一个接口，并保持数据、训练步数、采样器、参数量/FLOPs 尽量一致；⑤至少比较 baseline、目标改动和容量匹配对照，并报告多随机种子；⑥同时查看训练损失、梯度/激活、收敛速度、文本对齐、运动质量和计算成本；⑦若小模型有效，再验证收益能否随规模保持。

例如研究双流/单流时，可比较 60 层单流、20 双流 + 40 单流，以及参数/FLOPs 匹配的其他分配；同时测文本条件敏感度、图像/视频损失、模态梯度冲突与最终质量。只有当结果支持原假设，才能说结构设计有效；否则它只是合理故事。论文架构通常来自前人组件、系统约束和大量失败实验，最终论文图会隐藏这段搜索过程。

**困惑二：Drifting 这类抽象方法是怎样构思出来的？**

它往往不是先“猜出一个公式”，而是先换一种提问方式：既然扩散或 Flow 在推理时反复移动样本，能否把这种逐步演化转移到训练阶段，让生成器最终一步就产生正确分布？接着写出必须满足的条件：当生成分布等于真实分布时，更新应达到平衡；生成样本偏离真实分布时，应受到真实样本的吸引和其他生成样本形成的排斥。最后才构造可计算的核函数、stop-gradient 伪目标并做实验验证。因此这类抽象创新更像：**重新定义研究对象 → 写出必须满足的约束 → 构造最简单的可训练形式 → 用理论、玩具实验和消融逐层验证**。

### 可直接使用的总结

> 这组工作展示了一条清晰的演进路线：DiT 证明扩散模型可以采用通用 Transformer 骨干；Sora 把图像 patch 推广为统一的时空 patch；HunyuanVideo 和 Wan 说明大型视频模型必须联合设计视频 VAE、文本编码、Flow Matching、渐进训练和系统优化；LingBot-Video 则利用稀疏 MoE 扩大容量，并用物理奖励与动作条件探索具身世界模型。视频模型正在从追求感知逼真转向学习可控的状态转移，但目前的物理一致性和因果可靠性仍不足以支持完全可信的世界模拟。

## 7. 论文相关问答

### Q5：Sora 为什么能称为世界模拟器，又为什么不能说它已是世界模型？

它展示了 3D 一致性、物体持续性和部分交互模拟，说明大规模视频模型可能学到世界规律。但这些多是定性结果，仍存在物体消失、变形、穿透和因果错误，也缺少动作闭环与可验证的状态预测。因此应称为“世界模拟潜力”，而不是可靠世界模型。

### Q6：视频模型为什么特别需要 MoE？

视频 token 极多，稠密扩大参数会同时提高每个 token 的计算成本。MoE 让模型拥有更大总容量，但每个 token 只激活少量专家，从而解耦容量与激活计算。代价是路由均衡、专家通信、显存和部署更加复杂。

### Q8：Peebles 和谢赛宁为什么能用 Transformer 替代 U-Net？整体数据如何流动？

这并不是突然发现了一个只能由 Transformer 完成的新任务，而是把几条已经成熟的思路接了起来：

1. ViT 已证明图像可以切成 patch，当作 token 序列交给 Transformer；
2. 语言模型和 ViT 表明 Transformer 的性能往往能随模型规模和训练计算稳定提升；
3. latent diffusion 先用 VAE 压缩图像，使 token 数大幅减少，全局 self-attention 变得可承受；
4. 扩散模型的去噪目标不限制网络结构，因此可以直接询问：“如果把 U-Net 换成标准 Transformer，规模收益是否更清晰？”

DiT 的重要性并不只是“有人第一次想到 Transformer”，而是 Peebles 和谢赛宁给出了一套简洁、可扩展的替换方案，并系统验证了模型大小、patch 大小和计算量与生成质量的关系。

#### 训练时的数据流

```text
原始图像 x
   ↓ VAE Encoder：把像素压缩到潜空间
干净 latent z₀
   ↓ 随机选择时间步 t，并加入噪声 ε
带噪 latent z_t
   ↓ Patchify：用步幅等于 patch 大小的卷积切块
空间 token 序列
   ↓ 加入位置编码；用 adaLN-Zero 注入时间步 t 和类别 c
一串 Transformer blocks：全局 self-attention + MLP
   ↓ 线性层把每个 token 还原成一个 latent patch
Unpatchify：按原来的空间位置拼回特征图
   ↓
预测噪声 ε̂（以及论文实现中的方差参数）
   ↓
与真实噪声 ε 计算训练损失
```

其中，**Patchify 和 Unpatchify 是连接卷积式图像表示与 Transformer 序列表示的两个接口**。每个 patch token 始终对应 latent 中的一个固定区域，位置编码告诉 Transformer 各区域在哪里，因此去掉 U-Net 的跳跃连接并不等于丢掉全部空间位置。

原始 DiT 是类别条件模型。时间步 $t$ 和类别 $c$ 分别编码后合并，用来调制每个 Transformer block 的 LayerNorm。效果最好的 adaLN-Zero 还为注意力和 MLP 残差分支生成门控参数，并将门初始化为 0，使网络训练初期近似恒等映射，再逐渐学会修改特征。后续文本到图像或视频模型则常用 cross-attention、双流结构等方式接入文本 token。

#### 推理时的数据流

```text
随机高斯 latent z_T
   ↓
DiT 预测当前时间步的噪声
   ↓ 扩散采样器根据预测更新 latent
z_T → z_{T-1} → ... → z₀
   ↓ VAE Decoder
生成图像
```

DiT 本身只负责“给定当前带噪 latent，预测该怎样去噪”；扩散采样器负责反复调用 DiT 并更新 latent，VAE Decoder 最后负责从潜空间恢复像素。这样，U-Net 原来承担的去噪骨干角色被 Transformer 替换，但 VAE、加噪过程、训练目标和采样器仍可保持不变。

> 最简记忆：U-Net 用“降采样—升采样—跳跃连接”组织二维特征；DiT 用“patchify—Transformer—unpatchify”组织同一批空间信息。真正完成接口替换的是 patch/token 变换、位置编码、条件调制和输出重排。
