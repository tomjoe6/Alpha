# 视频生成模型中的显式物理规律与 Reward 设计

## 先给结论：从“球下落并反弹”开始最合适

如果要增强视频模型的物理性，最容易落地的场景是：**固定相机、静止地面、单个刚性球自由下落并反弹。**它能同时测量：

1. 空中阶段是否近似恒定重力加速度；
2. 球是否穿过地面；
3. 碰撞前后速度是否满足合理恢复系数；
4. 没有外部能量输入时，反弹高度是否凭空增加；
5. 球的半径、形状和身份是否保持。

这类场景比“一个人在街上走路是否符合物理”更适合做 reward，因为对象、接触时刻和适用公式都比较明确。

## 什么样的物理规律适合做 Reward

一个实用的物理指标最好同时满足：

- **可观测**：能从像素、深度、关键点或跟踪结果估计；
- **适用条件明确**：只在物体悬空、发生碰撞等对应阶段计算；
- **尺度尽量无关**：没有真实米制尺度时，仍能使用比值或一致性；
- **不容易作弊**：模型不能只靠让画面静止、遮住物体或移动相机获得高分；
- **可分解**：知道失败来自穿透、加速度、碰撞还是物体消失。

物理规律越显式，通常对场景假设要求越强。开放世界视频很难仅凭 2D 像素验证严格的能量或动量守恒，因此应先从受控 prompt 和可测子任务训练。

## 候选物理规律

| 规律 | 可测量残差 | 需要的状态 | 可行性与限制 |
|---|---|---|---|
| 物体持续性 | 跟踪 ID 丢失、无因出现/消失 | 检测、分割、跟踪 | 最容易，但要区分遮挡与真正消失 |
| 刚体形状保持 | 物体内部点间距离、面积/体积变化 | mask、关键点、深度 | 透视会改变 2D 面积，最好使用 3D 或相对距离 |
| 非穿透约束 | 两物体或物体—地面的负间距 | mask、深度、接触面或 SDF | 很适合惩罚穿模；遮挡可能造成误判 |
| 恒重力加速度 | 空中轨迹二阶差分是否近似常量 | 物体中心、时间间隔、重力方向 | 无尺度时只能测“恒定且方向一致”，难直接验证 $9.8\,m/s^2$ |
| 无外力匀速 | 水平速度变化或加速度残差 | 位置、相机运动补偿 | 必须确认没有推力、摩擦或碰撞 |
| 碰撞恢复系数 | 碰撞前后法向相对速度比 | 接触时刻、法向、速度 | 可用无量纲比值，较适合球—地面碰撞 |
| 动量守恒 | 碰撞前后总动量差 | 质量、3D 速度 | 质量通常不可见，适合已知物体或合成数据 |
| 能量不凭空增加 | 动能+势能变化减外力做功 | 质量、尺度、速度、高度 | 开放视频难；反弹高度单调下降是更稳的代理 |
| 关节与骨长约束 | 骨长变化、关节越界、肢体断裂 | 人体/机器人关键点 | 对人物和机器人视频非常实用 |
| 接触与无滑动 | 脚接地时的相对地面速度 | 足部关键点、地面、相机姿态 | 可检测 foot skating，但要识别真实滑行动作 |
| 流体近似不可压缩 | 速度场散度、区域体积变化 | 稠密流场、深度或 3D 网格 | 2D optical flow 不等于真实流体速度，只能做近似 |
| 多视角几何一致性 | 深度重投影、光流 warp、遮挡残差 | 深度、相机位姿、光流 | 属于几何一致性，不是力学定律，但很重要 |

## 推荐实验：球下落—碰撞—反弹

设相机固定，竖直向上为正方向。跟踪得到球心高度 $h_t$、水平位置 $x_t$、半径 $r_t$，地面高度设为 0，帧间隔为 $\Delta t$。

**1. 空中重力一致性**

球未接触地面时：

$$
a_t^y
=\frac{h_{t+1}-2h_t+h_{t-1}}{\Delta t^2}
\approx-g.
$$

如果没有米制尺度，不必强制 $g=9.8$；可以在一段轨迹内拟合一个共享的 $\hat g>0$，奖励“加速度近似恒定、方向与地面法向一致”：

$$
E_{\text{grav}}
=\frac{1}{|\mathcal A|}\sum_{t\in\mathcal A}
\rho(a_t^y+\hat g).
$$

$\mathcal A$ 是可信的空中帧，$\rho$ 可用 Huber loss，降低跟踪抖动的影响。

**2. 水平无外力一致性**

若 prompt 没有水平外力：

$$
E_{\text{horizontal}}
=\frac{1}{|\mathcal A|}\sum_{t\in\mathcal A}
\rho\left(rac{x_{t+1}-2x_t+x_{t-1}}{\Delta t^2}\right).
$$

**3. 非穿透约束**

球底部不应低于地面：

$$
h_t-r_t\ge0,
$$

$$
E_{\text{penetration}}
=\frac1T\sum_t\operatorname{ReLU}(r_t-h_t)^2.
$$

**4. 碰撞恢复系数**

设碰撞前法向速度 $v^-$ 向下、碰撞后 $v^+$ 向上：

$$
e=-\frac{v^+}{v^-}.
$$

普通被动碰撞通常满足 $0\le e\le1$。可惩罚超出区间的值：

$$
E_{\text{restitution}}
=\operatorname{ReLU}(-e)^2
+\operatorname{ReLU}(e-1)^2.
$$

若已知材质，例如“橡胶球”或“黏土球”，还可以为 $e$ 设置不同的软区间，而不是所有物体使用同一阈值。

**5. 能量衰减代理**

没有外力输入时，连续反弹的最高点通常不应越来越高：

$$
H_{k+1}\le H_k,
$$

$$
E_{\text{energy}}
=\sum_k\operatorname{ReLU}(H_{k+1}-H_k)^2.
$$

这不等价于严格能量守恒，但在未知质量和尺度时比直接计算焦耳更可靠。

**6. 形状与身份保持**

$$
E_{\text{shape}}
=\frac{\operatorname{Var}(r_t)}{(\operatorname{Mean}(r_t)+\varepsilon)^2},
$$

再加入跟踪置信度、物体消失和复制惩罚，避免球在碰撞时突然变形、分裂或换成另一个物体。

## Reward 如何组合

不要直接把未经归一化的误差相加。可以先把各残差映射到 $[0,1]$：

$$
R_i=\exp(-E_i/\tau_i),
$$

再按适用阶段和置信度加权：

$$
R_{\text{physics}}
=\frac{\sum_i w_i\,m_i\,q_i\,R_i}
{\sum_i w_i\,m_i\,q_i+\varepsilon}.
$$

- $m_i$：规律是否适用，例如只有空中阶段才计算重力；
- $q_i$：检测、深度、跟踪等感知模块的置信度；
- $w_i$：任务权重；
- $\tau_i$：不同量纲的归一化尺度。

最小伪代码：

```python
def ball_physics_reward(video, prompt):
    state = perception(video)  # 球心、半径、地面、接触、置信度

    e_grav = gravity_residual(state.airborne_track)
    e_horizontal = horizontal_acceleration(state.airborne_track)
    e_pen = penetration_depth(state.ball, state.ground)
    e_bounce = restitution_violation(state.contact_events)
    e_energy = increasing_bounce_height(state.bounce_peaks)
    e_shape = radius_and_identity_variation(state.ball_track)

    errors = [e_grav, e_horizontal, e_pen, e_bounce, e_energy, e_shape]
    rewards = [torch.exp(-e / tau[i]) for i, e in enumerate(errors)]

    # mask：该规律是否适用；confidence：感知是否可靠
    return confidence_weighted_mean(rewards, state.masks, state.confidence)
```

## 三个可观测层级

| 层级 | 能可靠测什么 | 不应过度声称什么 |
|---|---|---|
| 仅 RGB / 2D | 身份持续、明显穿透、2D 轨迹、骨长、脚滑 | 严格 3D 动量、真实重力数值、体积守恒 |
| RGB + 单目深度/相机估计 | 相对 3D 轨迹、接触、地面法向、近似加速度 | 精确米制能量和质量 |
| 已标定多视角/合成环境 | 3D 速度、碰撞、动量、能量、SDF 非穿透 | 仍需考虑材质、外力和隐藏状态 |

因此，开放互联网视频更适合训练“物理合理性代理”；严格定律 reward 最好使用模拟器、已知初始条件或专门拍摄的数据校准。

## Reward hacking：最需要防的失败

1. **静止作弊**：完全不运动会获得低加速度和高平滑分。必须同时要求 prompt 指定的位移、动作幅度或任务完成。
2. **遮挡作弊**：物体消失后无法测穿透。应加入物体持续性和可见性 reward。
3. **相机作弊**：移动相机可伪造物体速度。必须先估计并消除 camera motion，或使用固定相机训练集。
4. **缩小/模糊作弊**：让物体很小可降低几何误差。应约束清晰度、尺寸和构图。
5. **感知器漏洞**：生成对检测器友好但人眼错误的图像。应使用多模型 ensemble、人工抽检和对抗负样本。
6. **规律误用**：把主动机器人、火箭或魔法场景按自由落体惩罚。必须由 prompt、场景分类和接触状态控制 applicability mask。

## 从单项 Reward 扩展到视频世界模型

推荐按难度形成 curriculum：

```text
单物体持续与非穿透
→ 重力下落和单次碰撞
→ 多物体碰撞与摩擦
→ 关节机器人和动作条件
→ 流体、柔体与复杂交互
→ 闭环控制下的长期因果一致性
```

后续更值得做的方向是：

- 在模型 latent 中增加显式状态头，预测深度、位姿、速度、接触和不确定性，再对状态施加物理残差；
- 使用可微渲染或 3D scene flow，使 reward 从 2D 像素提升到 3D 世界坐标；
- 把物理定律写成可组合程序，根据 prompt 自动选择适用规则；
- 将物理 reward 与文本一致性、视觉质量、多样性和任务成功 reward 共同优化；
- 使用反事实动作对：只改变一个动作，检查未来结果是否随干预发生一致变化。

> 最简建议：第一版不要直接做“万能 Physics Reward Model”。先做固定相机的球下落数据集，用重力残差、非穿透、恢复系数、反弹高度和形状保持五项可解释 reward，验证它是否真的能减少穿模、悬浮、加速突变和能量凭空增加。
